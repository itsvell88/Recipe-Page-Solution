### What I learned

(1) I learned how to classify contents and choose suitable semantic mark-ups.
(2) Breaking down contents into smaller parts.
(3) How to build a responsive page that works on both desktop & mobile.
(3) How to create table with CSS grid.

### Continued development

I want to make breaking down contents into smaller parts and plan the sections ahead before coding as a habit, and a mandatory thing to do before starting any kind of project. I feel like still have to optimise using container for sections or parts for easy styling in CSS. The next thing I'm looking forward to is learning how to build interactive page, clickable buttons, links, like a real website. Also, it might be fun to try building multiple pages web as it would be helpful to undestand how all the htmls and csss linked.
